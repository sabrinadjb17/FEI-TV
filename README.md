# 🌸 Sobre o projeto

O **FEITV** é um sistema desenvolvido em **Linguagem C** que simula uma plataforma de streaming de vídeos.

O projeto foi construído utilizando programação estruturada, modularização e manipulação de arquivos, permitindo que os dados permaneçam salvos entre diferentes execuções do programa.

Todas as informações são armazenadas em arquivos **CSV**, funcionando como um pequeno banco de dados.

# 🎯 Objetivo acadêmico

O objetivo deste projeto foi aplicar, na prática, os conceitos vistos durante a disciplina, desenvolvendo um sistema completo dividido em módulos e utilizando arquivos para armazenamento permanente das informações.
